# 前端 UI 一律参考 awesome-design-md 设计系统

只要任务涉及前端界面（HTML/CSS/JavaScript/TypeScript、React/Vue/小程序、页面或组件、配色 / 字体 / 间距 / 圆角 / 阴影 / 动效 / 响应式），在动手写代码前必须：

1. 先明确本次界面的**实际需求**（产品类型、目标用户、信息密度、明 / 暗、品牌调性），据此在 `awesome-design-md/design-md/` 中挑选最贴近的 1 套作为**参考基准**；必要时再借鉴另外 1–2 套的**局部**优秀做法，并保持主辅关系。
2. 完整阅读所选 `DESIGN.md`，**学习并提炼**其配色逻辑、字体层级、间距节奏、组件与状态处理、Do's & Don'ts，转化为可复用的设计令牌与原则——目标是借鉴设计语言，而不是整站照搬。
3. 结合本项目需求对令牌 / 布局做必要调整，调整处需说明理由。
4. 不得直接复刻他人品牌标识、商标或专有字体等受保护素材；借鉴的是设计语言与决策方法。
5. 用户未指定风格时，主动推荐一个参考基准并说明选型理由，再按其执行。

完整工作流与落地规范见技能 `.trae/skills/design-md-ui/SKILL.md`，选型清单见其 `references/catalog.md`。
